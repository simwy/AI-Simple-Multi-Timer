# 大屏计时器 · 使用说明

一款横屏使用的大屏计时工具，集时钟、正计时、倒计时、番茄钟于一体。数字大、按钮少，放在桌上、墙上或支架上，抬眼就能看清。

> 小程序为横屏界面，请将手机横过来使用。

---

## 一、快速上手

1. 打开小程序，默认进入「时钟」模式，主时间显示当前时间。
2. 在顶部「模式栏」点选要用的模式：**时钟 / 正计时 / 倒计时 / 番茄**。
3. 倒计时、番茄未开始时，直接在**主时间上上下滑动**就能调时长；也可以点底部设置栏里的时长按钮，用「时 : 分 : 秒」输入框设置。
4. 点右侧圆形「开始」按钮开始计时；需要暂停点「暂停」，需要归零点「重置」。
5. 点屏幕空白处可进入**专注模式**，只保留时间显示，再点一下恢复。

## 二、界面速览

| 区域 | 位置 | 作用 |
| --- | --- | --- |
| 模式栏 | 顶部居中 | 切换时钟 / 正计时 / 倒计时 / 番茄 |
| 子时间区 | 主时间上方 | 日期、当前阶段、计次预览等辅助信息 |
| 主时间区 | 屏幕中央 | 大号时间数字；倒计时 / 番茄未开始时可直接滑动调时 |
| 操作组 | 屏幕侧边（默认右侧） | 重置 / 暂停 / 开始三个圆形按钮 |
| 设置栏 | 底部居中 | 模式专属设置 + 通用外观设置，分两行 |

界面上的区域名称统一为：右侧圆形按钮组叫「**操作组**」，底部胶囊按钮行叫「**设置栏**」。

## 三、四种模式

### 3.1 时钟

- 主时间显示当前时间；子时间显示日期和星期，使用 12 小时制时还会显示「上午 / 下午」。
- 设置栏专属项：
  - **闹钟**：设置一次性的「时 : 分」闹钟。
  - **时制**：24 时 / 12 时切换。
  - **显示秒**：开 / 关。关闭后主时间只显示「时:分」。
  - **计次**：开 / 关，开启后操作组对侧出现「计次」按钮。
- 时钟模式没有开始、暂停、重置；操作组不显示。

**闹钟说明**

- 点「闹钟」→ 输入时、分 → 点「确定」。主时间下方会显示「闹钟 08:30」。
- 闹钟为一次性：到点提醒后会**自动关闭**，不会每天重复。
- 闹钟设成当前的「时:分」会立即提醒一次。
- 小程序在后台或锁屏期间若已过了闹钟时间 10 分钟以上，不会补响，会顺延到下一次同一时刻。
- 闹钟设置后切换到其他模式仍然有效，到点照样提醒。
- 再次点「闹钟」可修改，弹层里的「关闭闹钟」可取消。

**计次说明**

- 时钟下的「计次」记录的是点击那一刻的**当天时刻**（如 14:32:05）。
- 主时间下方最多预览最近 2 次，更早的点击「More」查看全部。
- 时钟计次列表里可以「清空」。

### 3.2 正计时

从 0 开始累计，适合记录持续了多久。

- 点「开始」计时，点「暂停」定格，点「继续」接着走，点「重置」归零。
- 设置栏专属项：
  - **结束时长**：设置一个上限，到达后自动停止并提醒；显示「不限」时不限时。
  - **计次**：开 / 关。
- 子时间显示当前日期和时间（时:分），随分钟更新。
- 到达结束时长后显示「时间到」，再点「开始」会从 0 重新计时并清空计次。

**计次说明**

- 运行中才能计次，「计次」按钮在未运行时为灰色。
- 每条记录同时显示累计时间和相对上一条的分段用时（「+分:秒.百分秒」）。
- 列表按最新在前排列；正计时的计次不能单独清空，点「重置」会连同计时一起清空。

### 3.3 倒计时

从设定时长倒数到 0。

- **未开始时**，主时间是一排可编辑的数字，可以直接**上下滑动某一位**调整（详见第五节）。
- 也可以点设置栏的「倒计时长」，在弹层中输入「时 : 分 : 秒」后点「确定」。
- 点「开始」倒数；「暂停」定格，再点「继续」接着倒数。
- 时间到后显示「时间到」并按「结束提醒」设置提醒。
- 子时间显示当前日期和时间（时:分）。
- 「重置」有一个细节：**第一次重置回到你手动设置的时长，第二次重置回到默认的 1 分钟**，之后再重置会在这两者之间交替。这样既能快速回到常用时长，也能一键回到默认值。

### 3.4 番茄

工作与休息交替的番茄工作法。

- 默认工作 25 分钟、休息 5 分钟。
- **未开始时**，主时间同样是可滑动调整的，默认调整的是当前阶段（工作）的时长；也可以点设置栏的「工作时长」「休息时长」分别设置。
- 点「开始」进入工作阶段。子时间显示「工作时间 · 第 1 个番茄」。
- 工作结束：显示「时间到」，并出现「进入休息时间 05:00」的提示，**点这条提示**进入休息阶段。
- 休息结束：出现「进入工作时间 25:00」，点它开始下一个番茄。
- 子时间会显示已完成的番茄个数，例如「休息时间 · 已完成 1 个番茄」。
- 番茄阶段结束时，「开始 / 暂停」按钮会置灰，必须点中间的「进入休息 / 进入工作」提示才能继续，避免误触。
- 「重置」会把阶段回到工作、完成数清零，并把工作 / 休息时长在你手动设置值与默认值之间交替（同倒计时逻辑）。

## 四、操作组：开始 / 暂停 / 重置

操作组位于屏幕侧边，默认在右侧。

- **开始**：开始计时。暂停过后按钮会变成「继续」。
- **暂停**：暂停计时，再点开始可接着走。
- **重置**：回到未开始状态，具体行为见各模式说明。
- **按钮位置**：设置栏第二行的「按钮位置」可在「正 / 反」之间切换，把操作组挪到屏幕左侧或右侧，方便左手或右手操作。
- 开启「计次」后，「计次」按钮会出现在操作组的**对侧**，两边互不遮挡。

## 五、滑动调时

倒计时、番茄在未开始时，主时间的每一位数字都可以单独调整：

- 在某一位数字上**向上滑，数字增大；向下滑，数字减小**。
- 每滑过一小段距离（约 24px）变化 1。
- 时、分、秒、百分秒的每一位独立调整；分和秒的十位最大到 5，其余位最大到 9。
- 松开手指后新的时长会自动保存，下次打开仍是这个值。
- 主时间下方有「上下滑动调整」的提示，第一次滑动后会淡出。
- 计时一旦开始，主时间恢复为普通显示，不能再滑动；需要修改请先「重置」。

## 六、设置栏

设置栏在底部，分两行：

- **第一行**：当前模式的专属设置 + 「更多」。
- **第二行**：通用外观与行为设置，默认收起，点「更多」展开 / 收起。展开或收起时，第一行位置保持不变。

### 6.1 第一行（随模式变化）

| 模式 | 按钮 |
| --- | --- |
| 时钟 | 闹钟、时制、显示秒、计次、更多 |
| 正计时 | 结束时长、计次、更多 |
| 倒计时 | 倒计时长、更多 |
| 番茄 | 工作时长、休息时长、更多 |

### 6.2 第二行（通用设置）

| 设置 | 可选值 | 说明 |
| --- | --- | --- |
| 背景颜色 | 深色 / 浅色 | 整页背景与系统胶囊按钮样式同步切换 |
| 数字颜色 | 白色 / 绿色 / 青蓝 / 琥珀 | 循环切换主时间数字颜色 |
| 字体 | 数码管 / 圆角 / 经典 | 数码管为七段风格，圆角偏柔和，经典为系统字体 |
| 字号 | 小 / 中 / 大 / 超大 | 调整主时间数字大小，默认「大」 |
| 精度 | 低 / 高 | 低：显示到秒；高：显示到百分秒 |
| 渐变 | 开 / 关 | 主时间数字的渐变效果 |
| 子时间 | 显示 / 隐藏 | 是否显示主时间上方的辅助信息 |
| 结束提醒 | 振动+提示音 / 振动 / 提示音 / 无 | 每次切换会立即试听 3 下 |
| 按钮位置 | 正 / 反 | 操作组放在右侧或左侧 |
| 重置设置 | 恢复默认 | 所有外观设置、各模式时长、闹钟全部恢复默认 |

> 注意：时钟模式关闭「显示秒」时，即使精度为「高」也不会显示百分秒。
> 所有设置都会自动保存，下次打开小程序仍然有效。

## 七、结束提醒

以下情况会触发结束提醒：

- 倒计时倒数到 0；
- 正计时到达「结束时长」；
- 番茄的工作或休息阶段结束；
- 时钟闹钟到点。

提醒方式由设置栏的「结束提醒」决定：振动、提示音、两者或关闭。提醒会以「3 声一组、组间短暂停顿」的方式持续，最长约 1 分钟。

**想立刻停止提醒：点屏幕任意位置即可。** 在提醒过程中点击空白处只会停止提醒，不会切换专注模式。

时钟闹钟到点时还会弹出「闹钟时间到」提示，并自动关闭闹钟。

## 八、专注模式

- 点屏幕上的**空白区域**（非按钮、非弹层），即可进入专注模式：隐藏模式栏、操作组、设置栏等所有控件，只保留主时间与子时间。
- 再点一下空白处，恢复完整界面。
- 专注模式用来把设备当纯计时屏幕展示，例如放在桌上、投影或直播画面里。

## 九、数据保存与重置

- **会自动保存**：背景颜色、数字颜色、字体、字号、精度、渐变、子时间、结束提醒、按钮位置、计次开关、时制、显示秒，以及各模式手动设置的时长和闹钟。
- **不会保存**：正在进行的计时进度。彻底关闭小程序后再次进入，计时会回到未开始状态，但设置仍在。
- **重置设置**：点设置栏第二行最后的「重置设置」，所有设置与时长、闹钟立即恢复出厂默认（默认深色背景、白色数字、大字号、数码管、渐变开、精度低、子时间显示、结束提醒为振动+提示音、操作组在右侧）。

## 十、常见问题

**Q：时间到了但没有声音 / 没有振动？**
A：先看设置栏「结束提醒」是不是被切成了「无」；再检查手机是否静音、系统是否关闭了振动或小程序的通知权限。

**Q：切到后台或锁屏，计时还准吗？**
A：计时按真实时间计算。回到小程序时会自动对齐；如果后台期间已经到点，回来时会立即显示结束并提醒。但小程序被彻底关闭后，计时进度不会保留。

**Q：为什么番茄结束后「开始 / 暂停」按钮点不了？**
A：这是防误触设计。阶段结束后请点主时间下方的「进入休息时间 / 进入工作时间」提示继续。

**Q：怎么把按钮挪到左边？**
A：展开设置栏第二行的「更多」，点「按钮位置」，值变为「反」即可。

**Q：数字太小 / 看不清？**
A：展开「更多」，把「字号」调到「大」或「超大」，也可以换「数字颜色」和「字体」。

**Q：为什么分、秒的十位最多只能滑到 5？**
A：为了只显示合法的 00–59，分和秒的十位上限为 5，其余位上限为 9。
