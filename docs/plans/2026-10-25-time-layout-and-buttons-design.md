# 计时器页面主/子时间布局与按钮样式微调设计

- 日期：2026-10-25
- 主题：主时间精确垂直居中、子时间靠近主时间、主时间字号加大、设置栏缩小并区分标签/值颜色、操作组统一两种状态样式
- 状态：已确认
- 关联：`docs/plans/2026-10-25-timer-controls-ui-design.md`、`docs/plans/2026-10-25-timer-ui-tweaks-design.md`

## 目标

对横屏大屏计时器页面做五项纯视觉层调整，均不触碰计时引擎与状态机：

1. 主时间精确落在屏幕垂直中心。
2. 子时间更靠近主时间（上方）。
3. 主时间字号加大。
4. 设置栏胶囊更小，标签（第一行）与值（第二行）颜色层次拉开。
5. 操作组圆钮从「重置灰 / 开始绿 / 暂停琥珀」三套配色，统一为「可点击 / 不可点击」两种样式。

## 需求决策

| 项 | 决策 |
| --- | --- |
| 主时间精确居中 | 在 `.stage` 内主时间下方新增与 `.sub-time` 等高（34px）的空占位 `.stage-balancer`，使「子时间 + 主时间 + 占位」整组居中时，主时间恰好位于屏幕垂直中心 |
| 子/主时间间距 | `gap: 16px → 8px`；专注模式下同样成立 |
| 主时间字号 | `.main-time` 与 `.main-time__value` 的 `font-size` 由 `10vw → 13vw` |
| 设置栏胶囊尺寸 | `.toolbar-btn` 内边距 `6px 16px → 4px 12px`；标签字号 `14px → 12px`；值字号 `12px → 11px`；按钮间距 `gap: 10px → 8px` |
| 标签/值颜色 | 标签（`.toolbar-btn__desc`）`--pill-text → --fg`（更亮）；值（`.toolbar-btn__value`）保持 `--dim` |
| 操作组两种样式 | 可点击：`color: var(--fg)` + 中性灰半透明底 `rgba(128,128,128,0.15)`；不可点击：沿用 `opacity: 0.35` |
| 三配色去留 | 删除 `.action-reset` / `.action-start` / `.action-pause` 的颜色与背景规则，开始/暂停/重置不再有色差，只靠明暗区分状态 |

## 布局

横屏，从上到下：

```
┌──────────────────────────────────────────────┐
│            ┌────┬──────┬──────┬────┐         │  模式栏（不变）
│            │时钟│正计时│倒计时│番茄│         │
│            └────┴──────┴──────┴────┘         │
│                                              │
│              专注 · 第 1 个番茄               │  子时间（固定 34px 高）
│                    ↕ 8px                      │
│                12 : 34 : 56                  │  主时间（13vw，屏幕垂直中心）
│                                              │
│                （34px 空占位，不可见）        │  使主时间精确居中
│                                              │
│                                       ○ 重置 │  操作组：可点击=中性灰底+亮字
│                                       ○ 暂停 │  不可点击=opacity 0.35
│                                       ○ 开始 │
│    ┌────────┐┌────────┐┌────────┐┌────────┐  │  设置栏：胶囊更小
│    │数字颜色││背景颜色││按钮位置││工作时长│  │  标签=亮字 / 值=暗字
│    └────────┘└────────┘└────────┘└────────┘  │
└──────────────────────────────────────────────┘
```

`.stage` 仍为 `flex:1` 纵向居中；子时间与主时间间距由 `gap: 8px` 固定；主时间下方新增的 `.stage-balancer` 与 `.sub-time` 等高，抵消子时间在整组中的高度，使主时间成为整组的几何中心。

## 文件改动清单

| 文件 | 改动 |
| --- | --- |
| `miniprogram/pages/index/index.wxml` | `.stage` 内主时间 `.main-time` 之后新增空占位 `<view class="stage-balancer"></view>` |
| `miniprogram/pages/index/index.scss` | 新增 `.stage-balancer`；`.stage` 的 `gap` 16px→8px；`.main-time` 与 `.main-time__value` 的 `font-size` 10vw→13vw；`.toolbar-btn` 内边距、`.toolbar-btn__desc` / `__value` 字号、`.toolbar` 间距；`.toolbar-btn__desc` 颜色改 `--fg`；删除 `.action-reset` / `.action-start` / `.action-pause` 配色，`.action-btn` 基类统一为中性灰底 + `--fg` 字色 |

组件 WXML / TS 与计时逻辑均不改；无新增依赖、无存储键冲突。

## 边界与异常

- `--reset-fg` 变量在删除 `.action-reset` 配色后不再被引用，可保留也可一并清理（本轮倾向保留，避免影响其它引用）。
- 主时间 13vw 在 320px 宽屏下约 41.6px，8 位 `00:00:00` 仍能完整显示；需在 DevTools 568×320 下确认不贴边。
- 操作组失去颜色区分后，开始/暂停/重置的语义仅靠文字与明暗传达；若后续觉得可读性不够，再考虑保留一种轻度色差（本轮不主动加回）。
- `.stage-balancer` 为空 view，无文字无背景，仅占高度；`subTime` 为空时 `.sub-time` 仍占 34px，占位高度一致，主时间始终居中。
- 专注模式下 `.stage` 仍居中，主时间保持精确居中，逻辑不变。

## 不在本轮范围

- 主时间字号按可用宽度动态自适应。
- 操作组改为图标化或横向排列。
- 设置栏换行 / 折叠为更多行。
- 新的主题或配色方案。
- 计时引擎精度与状态机改动。

## 验证（无 CLI，DevTools 手测）

- 四种模式切换：主时间始终位于屏幕垂直中心；子时间紧贴主时间上方（间距明显小于现状）；切换不跳版。
- 主时间 13vw 字号在四种模式下完整显示，568×320 下不贴边。
- 设置栏胶囊整体变小，标签与值两行颜色层次清晰；番茄模式 5 个胶囊不换行溢出。
- 操作组：未运行时「暂停」置灰、「开始」可点击；运行中相反；「重置」始终可点击；三种可点击态视觉一致，两种状态恰好各一种样式。
- 深浅色主题、三种数字配色下布局与配色正常。
