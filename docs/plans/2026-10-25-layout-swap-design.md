# 计时器页面上下控件对调设计

- 日期：2026-10-25
- 主题：把模式切换移到顶部居中，把样式/主题/设置移到屏幕底部居中
- 状态：已确认
- 关联：`docs/plans/2026-10-25-timer-page-design.md`

## 目标

调整 `pages/index` 的控制区布局：

- 「时钟 / 正计时 / 倒计时」从底部 Tab 移到**顶部居中**，改为连体分段控件。
- 「样式 / 深浅色 / 设置」从顶部左侧移到**底部居中**，保持胶囊样式。
- 「样式」下拉菜单取消，改为点击循环切换配色。

## 需求决策

| 项 | 决策 |
| --- | --- |
| 顶部模式切换形式 | 连体分段控件（segmented control），选中段底色高亮 |
| 底部按钮形式 | 沿用现有胶囊样式，三个横排居中 |
| 样式切换交互 | 去掉下拉，点击按 白色 → 绿色 → 琥珀 → 白色 循环；胶囊文字显示当前配色 |
| 深浅色 / 设置 | 行为不变，设置仍为居中弹窗 |
| 日期 / 大数字 / 时间到 / 右下角操作 | 位置与样式不变 |

## 布局

横屏，从上到下：

```
┌──────────────────────────────────────────────┐
│          ┌──────┬────────┬──────┐   (· · ·)  │  分段控件居中；原生胶囊右上
│          │ 时钟 │ 正计时 │倒计时│            │
│          └──────┴────────┴──────┘            │
│              2026年10月25日 周日              │  仅时钟模式
│              12 : 34 : 56                    │  flex:1 居中
│                                    ○ 重置    │  右下角，位置不变
│                                    ○ 开始    │
│         ┌───────┐ ┌───────┐ ┌───────┐        │
│         │ 白色  │ │ 深色  │ │ 设置  │        │  底部胶囊居中
│         └───────┘ └───────┘ └───────┘        │
└──────────────────────────────────────────────┘
```

- **分段控件**：容器背景 `var(--tab-bg)`，全圆角，内边距 4px；三段等分，段内边距约 8px 24px、字号 22px、默认色 `var(--dim)`；选中段背景 `var(--tab-active-bg)`、文字 `var(--fg)`、全圆角。整体宽度约 300–330px，横屏居中后与右上原生胶囊保持安全间距（最窄 568px 横屏机型亦不重叠）。
- **顶部内边距**：沿用现有 12px，不额外预留右侧胶囊区（控件居中，无需 180px 右内边距）。
- **底部胶囊行**：flex 横排、居中、`gap: 10px`，内边距 `12px 0 24px`；`.pill` 样式沿用。
- **右下角操作**：保持 `right: 32px; bottom: 120px`，位于底部胶囊行上方。
- **日期、大数字、时间到提示**：样式与定位不变。

## 交互

1. **模式切换**：点击分段项切换模式；运行中切换仍先暂停（保持现状）。`onSwitchMode` 不再清理下拉菜单状态。
2. **样式**：点击胶囊循环切换 `white → green → amber → white`，立即生效并写入 `wx.setStorageSync('timer.style')`。胶囊文字随当前样式显示「白色 / 绿色 / 琥珀」。
3. **深浅色**：点击切换 `dark / light`，持久化不变。
4. **设置**：点击打开居中设置面板，行为不变。

## 边界与异常

- 分段控件必须在横屏各宽度下与右上胶囊不重叠：控制字号与内边距，避免超过约 340px。
- 浅色主题下分段控件与胶囊仍使用 CSS 变量，无硬编码颜色。
- 底部胶囊行不遮挡内容：大数字区域 `flex: 1`，控件行在常规文档流中，非绝对定位。
- 样式循环从持久化值起步，重进页面不重置。

## 验证（无 CLI，DevTools 手测）

- 三种模式在顶部分段控件切换，选中态正确，运行中切换会暂停。
- 样式胶囊循环三次回到原色，重进页面保持上次配色。
- 深浅色切换与设置面板正常，重进保持。
- 横屏窄机型（如 iPhone SE）下分段控件不压到原生胶囊。
- 倒计时/正计时运行时，右下角按钮与底部胶囊不重叠。
- 日期仅时钟模式显示。
