# 计时器页面控制区与字号微调设计

- 日期：2026-10-25
- 主题：子/主时间成组固定间距、操作组三固定按钮并缩小、设置栏新增按钮位置、模式框字号缩小
- 状态：已确认
- 关联：`docs/plans/2026-10-25-timer-ui-tweaks-design.md`、`docs/plans/2026-10-25-layout-swap-design.md`

## 目标

对横屏大屏计时器页面做四项调整，其中三项为纯视觉/交互层改动，一项（三固定按钮）需要给计时组件补充公开方法：

1. 子时间与主时间之间只保留约「子时间文字高度」的间距，且不再随屏幕高度变化。
2. 操作组圆钮缩小，显示更精致。
3. 正计时、倒计时、番茄统一为「重置 / 暂停 / 开始」三个固定按钮；设置栏新增「按钮位置」，可在左/右之间切换，默认右侧。
4. 顶部四个模式框的字号调小。

## 需求决策

| 项 | 决策 |
| --- | --- |
| 子/主时间布局 | 新增 `.stage` 包裹两者，`flex:1` 纵向居中，`gap:16px` 固定；`.sub-time` 去掉 `margin-top`，保留 `height:34px` 占位；`.main-time` 由 `flex:1` 改为 `flex:none` |
| 视觉间距依据 | 子时间字号 22px，行盒上下留白各约 6px，`gap:16px` 对应视觉间距约 22px，等于子时间文字高度；最终在 DevTools 微调 |
| 三固定按钮范围 | 正计时、倒计时、番茄统一；时钟无操作组，保持不变 |
| 按钮文案 | 固定为「重置」「暂停」「开始」，不再出现「开始/暂停」合一按钮 |
| 置灰规则 | 未运行时「暂停」置灰，运行中「开始」置灰；置灰按钮可点但组件方法幂等 |
| 操作钮尺寸 | 直径 64px（原 88px），字号 16px（原 20px），间距 10px（原 16px），整组高 212px |
| 操作组位置 | `bottom:120px` 改为 `90px`；默认 `right:32px`，左侧时 `left:32px` 且 `right:auto` |
| 按钮位置设置 | 设置栏新增两行胶囊「按钮位置 / 右侧或左侧」，点击在左右间切换；仅当前模式有操作组时显示 |
| 持久化 | `timer.actionSide` 存 `'left' | 'right'`，默认 `'right'`，非法值回落右侧 |
| 模式框字号 | `.mode-tab` 22px → 17px，`padding 8px 12px` → `7px 11px`，`line-height 1.5` → `1.4` |
| 子时间字号 | 保持 22px 不改 |
| 主时间字号 | 保持 10vw 不改 |

## 布局

横屏，从上到下：

```
┌──────────────────────────────────────────────┐
│            ┌────┬──────┬──────┬────┐         │  模式栏（字号 17px）
│            │时钟│正计时│倒计时│番茄│         │
│            └────┴──────┴──────┴────┘         │
│                                              │
│              专注 · 第 1 个番茄               │  子时间（固定 34px 高）
│                    ↕ 固定 16px                │
│                12 : 34 : 56                  │  主时间（10vw）
│                                              │
│                                       ○ 重置 │  操作组：直径 64px、间距 10px
│                                       ○ 暂停 │  bottom:90px，默认右侧
│                                       ○ 开始 │
│    ┌────────┐┌────────┐┌────────┐┌────────┐  │
│    │数字颜色││背景颜色││按钮位置││工作时长│  │  设置栏两行胶囊
│    └────────┘└────────┘└────────┘└────────┘  │
└──────────────────────────────────────────────┘
```

`.stage` 占据模式栏与设置栏之间的全部剩余高度，子时间与主时间作为一组在其中垂直居中；两者间距由 `gap` 固定，与屏幕高度无关。

## 交互

1. **开始**：调用激活组件的 `start()`；仅在未运行时启动。
2. **暂停**：调用 `pause()`；仅在运行中暂停。
3. **重置**：行为不变，调用 `reset()`。
4. **按钮位置**：点击胶囊在 `right ↔ left` 间切换，立即改变操作组贴边方向，并写入 `wx.setStorageSync('timer.actionSide')`；切换模式不重置；重进页面读取上次值。
5. **置灰按钮**：仍绑定点击，但 `start()` / `pause()` 内部先判断状态，重复点击无副作用。
6. **专注模式**：点击空白仍切换 `focusMode`，模式栏、操作组、设置栏一起隐藏，逻辑不变。

## 组件接口

| 组件 | 新增 | 说明 |
| --- | --- | --- |
| `stopwatch-timer` | `start()` / `pause()` | 内部复用 `_start()` / `_pause()`，先判断 `running` |
| `countdown-timer` | `start()` / `pause()` | 同上；结束后点击开始沿用 `_start()` 的重开逻辑 |
| `pomodoro-timer` | `start()` / `pause()` | 同上；阶段切换逻辑不变 |
| `clock-timer` | `start()` / `pause()` | 空实现，保持接口一致 |

页面移除对 `toggle()` 的调用（组件 `toggle()` 保留不删），新增 `onStart` / `onPause` 转发到当前激活组件。

## 边界与异常

- `timer.actionSide` 缺失或非法 → 使用 `'right'`，不写回存储也可。
- 三钮竖排高度 212px + `bottom:90px` = 302px，小于 iPhone SE 横屏高 320px，满足最小屏幕；若 DevTools 实测仍紧，优先减小 gap 到 8px。
- 番茄模式设置栏有 5 个胶囊（数字颜色 / 背景颜色 / 按钮位置 / 工作时长 / 休息时长），需在 568px 宽度下不换行溢出。
- 操作组切到左侧时与主时间数字在窄屏可能视觉接近，需在 568×320 下确认不遮挡；如遮挡，优先调整 `left/right: 32px` 为更小值或进一步缩小主时间字号（本轮不主动改）。
- 浅色主题下开始/暂停配色沿用 CSS 变量；暂停琥珀色为固定色值，与现有 `is-running` 一致。
- 置灰仅视觉，不阻止点击；幂等方法保证不会重复启动或重复暂停。

## 不在本轮范围

- 主时间字号按可用宽度动态自适应。
- 操作组改为横向排列或图标化。
- 计次 / 分段记录等功能。
- 设置面板重构、新的主题或配色方案。
- 改变计时引擎的计时精度与状态机。

## 验证（无 CLI，DevTools 手测）

- 四种模式切换：子/主时间间距一致，且明显小于当前；切换不跳版。
- 正计时 / 倒计时 / 番茄均显示「重置 / 暂停 / 开始」三钮，时钟无操作组。
- 未运行、运行中、倒计时/番茄结束三态下，暂停与开始置灰正确；连点置灰按钮无重复启动。
- 点击「按钮位置」左右切换，操作组贴边方向即时变化；重进小程序保持上次位置；手动写入非法存储值后回落右侧。
- iPhone SE 横屏（568×320）：三钮不压模式栏、不压设置栏；番茄 5 个胶囊不换行。
- 深浅色主题、三种数字配色下按钮与胶囊颜色正常。
