# AI-Simple-Multi-Timer

微信小程序大屏计时器（时钟 / 正计时 / 倒计时 / 番茄）。

## 页面 UI 术语约定

`pages/index` 页面各区域统一使用以下名称，代码注释与后续文档保持一致：

| 名称 | CSS 类 | 内容 | 位置 |
| --- | --- | --- | --- |
| 模式栏 | `.mode-bar` | 时钟 / 正计时 / 倒计时 / 番茄 | 顶部居中 |
| 子时间区 | `.sub-time` | 日期等次要信息 | 主时间区上方 |
| 主时间区 | `.main-time` | 大号数字时间 | 中部 |
| 结束提示 | `.time-up` | 「时间到」 | 主时间区上浮 |
| **操作组** | `.action-group` | 重置 / 开始暂停 | 右下角 |
| **设置栏** | `.toolbar` | 数字颜色 / 背景颜色 / 模式专属设置 | 底部居中 |
| 时长设置弹层 | `.panel` | 时:分:秒 输入 | 居中弹窗 |

> 「操作组」= 右下角圆形按钮（重置 / 开始暂停）；「设置栏」= 底部胶囊按钮行。二者名称不同，勿混用。
